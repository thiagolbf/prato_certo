### 🟢 Sugestões

#### R-01 — Formato de gramas a partir de 1.000 g é uma interpretação

- **Eixo:** 3. Aderência ao spec
- **Referência cruzada:** SPEC-UI seção 9: "gramas com separador de milhar e kg ao lado a partir de 1.000 g"
- **Evidência:** `web/src/lib/formato.ts`, função `formatarGramas`: `2100` vira `2.100 g (2,1 kg)`.
- **Descrição:** "kg ao lado" admite mais de uma leitura. A escolhida mostra os dois, gramas primeiro e kg entre parênteses. A outra seria mostrar só o kg. A SPEC não diz qual.
- **Sugestão de correção:** confirmar com quem definiu a SPEC na revisão da tela da T-41 ou T-50, que é onde o fechamento aparece. Se a escolha for outra, ajustar a função e o teste.

#### R-02 — `npm run build` não foi executado

- **Eixo:** 4. Cobertura de teste
- **Referência cruzada:** `web/src/app/layout.tsx` usa `next/font/google`
- **Evidência:** a verificação desta tarefa rodou `npm test`, `npm run typecheck` e `npm run lint`. O build não foi rodado.
- **Descrição:** o `next/font/google` baixa a fonte no build, e neste ambiente isso exige rede. O risco é o build de produção falhar por causa da fonte, o que só apareceria na publicação.
- **Sugestão de correção:** rodar `npm run build` em uma máquina com rede antes de publicar (T-61) e registrar o resultado.
